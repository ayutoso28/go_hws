# Домашние работы 2–3

Два отдельных Go-модуля: Gateway (HTTP-шлюз) и Ledger (транзакции в памяти). Требуется Go 1.22 или выше.

## Запуск

В первом терминале из корня репозитория:

```sh
cd hw02/gateway
go run .
```

Во втором терминале из корня репозитория:

```sh
cd hw02/ledger
go run .
```

Ledger выводит `Ledger service started`, демонстрирует проверку бюджетов и печатает сохранённые транзакции, затем завершает работу. Данные хранятся только в памяти. Нулевая сумма отклоняется, ID назначается автоматически, список возвращается как копия.

### Бюджеты (домашняя работа 3)

Запускайте Ledger из `hw02/ledger`: он читает файл `budgets.json` из текущего каталога через `os.Open` и `bufio.NewReader`.

`SetBudget` добавляет или обновляет фиксированный лимит категории в рублях. В `main` задаются бюджеты «Еда» — 4000 и «Транспорт» — 2000. Затем `LoadBudgets` загружает JSON-массив: обновляет лимит «Еда» до 5000 и добавляет «Образование» — 3000. При ошибке чтения или разбора JSON программа завершается с сообщением об ошибке.

Пример формата файла:

```json
[
  {"category": "Еда", "limit": 5000},
  {"category": "Образование", "limit": 3000}
]
```

В демонстрации сохраняются четыре транзакции: 450 и 4550 рублей на еду (ровно лимит), 70 на транспорт и 1200 на образование. Дополнительная трата 1 рубля на еду вызывает `budget exceeded` и не попадает в итоговый список. Категории без бюджета не ограничены. Лимиты учитывают все сохранённые транзакции категории, без разделения по датам.

### Проверка Gateway

Проверка Gateway: откройте http://localhost:8080/ping в браузере или выполните:

```sh
curl -i http://localhost:8080/ping
```

В Windows PowerShell используйте `curl.exe -i http://localhost:8080/ping`. Ожидаемый статус — `200 OK`, тело ответа — `pong`. Для остановки Gateway нажмите `Ctrl+C` в первом терминале.
