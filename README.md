# Домашние задания по курсу «Язык Go»

## Домашняя работа 1

Требуется Go версии 1.22 или выше. Проверить установленную версию:

```sh
go version
```

Программа в `hw01/main.go`:

- выводит имя пользователя из переменной окружения `USERNAME` в Windows или `USER` в Linux/macOS;
- выводит аргументы командной строки без имени самой программы;
- показывает версию Go через `runtime.Version()`.

Запуск из корня репозитория:

```sh
go run ./hw01 hello "аргумент с пробелами" 123
```

Запуск без аргументов:

```sh
go run ./hw01
```

Если имя пользователя не задано в окружении или аргументы не переданы, программа выводит соответствующее сообщение.

Ссылка для сдачи: https://github.com/ayutoso28/go_hws
